## 1. Common contract

- Auth (test `00-auth`): `workspaceTokenAuthAPIForScope` with scopes `pipelines`, `places`, `polls`; same rules as P1.12 §1.1 (401 `INVALID_CHATBOT_TOKEN`, 403 read-only before scope, 403 missing scope).
- A workspace token bypasses the pipeline ACL (`PIPELINE_TOKEN_SCOPE` acts like an admin); its changes have actor kind `workspaceToken`, `createdById: null`, and count as **automation** in stats.
- Errors as P1.12 §1.2: 422 `invalidRequestData` (`data.issues[].path`), `validationException` -> 422 `validation`, `notFoundException` -> 404 `notFound`, `conflictException` -> 409.
- Path ids are `zodBigintIdAsString` (digits only, non-zero).

## 7. Untested (with reason)

- Stage delete/move above 2000 items (queued bulk job, `queued:true`), `stageBusy` 409s: needs thousands of items.
- Pipeline ACL for members (`forbidden` 403, grant rules): needs a member session on the public API (tokens bypass the ACL).
- Assignment side effects (`assignContactOnAssign` → conversation assignment), automation events (`emitPipelineItemEvent`): other units' triggers.
- Field filters (`fieldConditions`, `fieldOperator`), activity actor filter, date-range filters on items: only the main filters are asserted.
- Poll voting in chat, after-vote flow run: chat path (P1 flows/messages units).
- Empty-body PATCH on stages/pipelines/vendors-like updates: risk of 500 (no column to set) — not asserted (P1.3 rule).

## 8. Original behavior the Rust port must match (surprises)

1. `placeCategories.create`, `placeLocations.create`, `polls.create` answer **200**; pipelines create/duplicate/createStage/createField/createItem/addComment **201**; `deleteStage` **200** with a body; `placeCategories.delete` **200** with a body.
2. `placeLocations.list` without paging returns all rows and `pageCount: 1` even for an empty list (other lists give 0).
3. Place category names are unique ignoring case and the error message is "Place category already exists" (not the declared "A place category with this name already exists").
4. Poll candidate count and date checks are business errors **400**, not 422.
5. Pipeline names get ` 2` suffixes, reference names `_2` (case-insensitive clash: "deals" after "Deals" becomes `deals` / `deals_3`).
6. A workspace token counts as **automation** in pipeline stats.
7. `transferItem` keeps the item id and number; field values follow the reference name.
8. `deleteStage` without `moveItemsToStageId` deletes the stage's items.
9. A contact identifier without its `id:` / `email:` / `phone:` prefix is a **404** `notFound` "Invalid identifier format" (not a 422).
10. Activity pages hold 10 entries newest first; with 12 entries page 1 ends with the comment and the status change.
