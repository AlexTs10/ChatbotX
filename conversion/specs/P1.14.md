## 1. Common contract

- Auth (test `00-auth`): scopes `ecommerce` (categories, vendors, products), `automation` (qrCodes, questionnaires, reflinks), `inbox` (realtime). Rules as P1.12 §1.1.
- Errors as P1.12 §1.2. A `notFoundException` on a route whose error map has no `notFound` (all **create** routes here) answers 404 `notFound` with **`defined:false`**.

## 7. realtime — test `60`

`getConnectToken` GET: needs a member — mobile access JWT + `x-workspace-id` (allowlisted route). Workspace API token -> **403** `FORBIDDEN` "A signed-in member session is required"; mobile JWT without workspace -> 400 `WORKSPACE_SELECTION_REQUIRED`; another workspace -> 403. 200 `{token,url,socketUrl}`: HS JWT `aud:"workspace:<ws>"`, `purpose:"member-connect"`, `userId`, `teamIds`, `iatMs`, `exp − iat = 60`; `url` = tenant public realtime URL, `socketUrl` = `ws(s)://…/rt/workspaces/<ws>`; the token opens the socket, a forged one is refused.

## 10. Original behavior the Rust port must match (surprises)

1. Create answers: categories/vendors/products **200**, questionnaires/qrCodes/reflinks/imports **201**, select/sync Meta Catalog **202**; product `update` and questionnaire `update`/`rename` **204**.
2. Not-found errors raised on create routes are `defined:false` (the route error map has no `notFound`).
3. Duplicates: product category **400** (case-sensitive per parent), vendor **400** (case-insensitive), QR/reflink **422** `validation`, questionnaire **409** `nameAlreadyExists`.
4. `products.update` is a full replace with create defaults; `products.list` has no defined order.
5. QR codes are stored and returned as `qr_<name>`; `qrCodes.create` returns only `{id}`; QR list has no default order.
6. `reflinks.create` requires `customFieldId` (null allowed) although it reads as optional.
7. `deleteSubmission`, `qrCodes.delete`, `reflinks.delete` answer 204 for unknown ids.
8. Only WhatsApp is a product-message channel (`listSendable`).
9. `realtime.getConnectToken` with a workspace token is 403 after auth (member required).
10. Vendor list without paging returns every row with `pageCount: 1`.
